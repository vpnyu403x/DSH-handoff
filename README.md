# deepseek-插件：离线交接包（dsh-handoff）
## 功能：

- 把「全部会话 + 它们各自的工作区 + 全部附件 + 插件自身」打包成**一个普通文件夹**，拷到另一台电脑后一条命令还原。**不经过网络，不依赖任何第三方包。**

## 安装：

- 本机：**插件 → 添加插件 → 选择本目录路径 → 打开DSH添加插件**（本目录就是包含 `package.json` 的那一层）。
- 装完输入 `/handoff` 查看用法，或在左侧会话上**点右键**。
